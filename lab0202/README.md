## Цель работы
Изучить создание и переключение веток Git, слияние изменений, разрешение конфликтов, использование rebase и работу с историей коммитов.

## Выполнение работы

### 1. Создание веток
Создан файл features.txt с основными функциями приложения.
Созданы ветки feature/payment и feature/notifications.

### 2. Слияние веток
Выполнено слияние feature/payment в lab0202-work.
При слиянии feature/notifications возник конфликт.
Конфликт разрешён вручную, изменения сохранены отдельным коммитом.

### 3. Работа с rebase
Создана ветка feature/database.
Добавлена конфигурация SQLite и PostgreSQL.
В рабочей ветке установлена MySQL.
Выполнен rebase и разрешён конфликт в config.txt.

### 4. Release
Создана ветка release/v1.0.
Добавлен файл version.txt с версией 1.0.0.

### 5. Самостоятельное задание
Созданы коммиты с первой, второй и третьей фичами.
Создан файл diff.txt.
Выполнен rebase ветки feature/third и разрешён конфликт.
Выполнено слияние ветки feature/third с lab0202-work.
Создан файл history.txt с историей коммитов.

## Результат
Изучены ветвление, слияние, разрешение конфликтов, rebase, создание release-ветки и просмотр истории Git.
