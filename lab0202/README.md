## 5. Контрольные вопросы

**1. Что такое ветка в Git?**

Ветка — это отдельная линия разработки, позволяющая работать над изменениями независимо от других веток. Она помогает разделять функциональность и не затрагивать основной код проекта.

**2. Для чего используется команда git branch?**

Команда git branch используется для просмотра, создания и удаления веток. Она позволяет управлять различными линиями разработки проекта.

**3. Чем отличается merge от rebase?**

Merge объединяет изменения двух веток, создавая коммит слияния. Rebase переносит коммиты одной ветки на новую базу, изменяя их историю и делая её более линейной.

**4. Что такое конфликт слияния?**

Конфликт возникает, когда Git не может автоматически объединить изменения, например когда разные ветки изменяют одни и те же строки файла.

**5. Как разрешить конфликт слияния?**

Необходимо открыть файл с конфликтом, вручную выбрать или объединить нужные изменения, удалить служебные маркеры конфликта, сохранить файл и выполнить git add. После этого завершить слияние коммитом или продолжить rebase командой git rebase --continue.

**6. Для чего используется параметр --no-ff?**

Параметр --no-ff запрещает Git выполнять fast-forward слияние и заставляет создавать отдельный коммит слияния. Это позволяет сохранить информацию о факте объединения веток.

**7. Для чего используется команда git log?**

Команда git log отображает историю коммитов. С помощью параметров можно просматривать краткую историю и граф ветвления.

**8. Что такое удалённый репозиторий?**

Удалённый репозиторий — это копия проекта, размещённая на сервере, например GitHub. Он позволяет хранить и обмениваться изменениями между разработчиками.

**9. Для чего используется команда git push?**

Команда git push отправляет локальные коммиты и ветки в удалённый репозиторий, публикуя изменения на сервере.
