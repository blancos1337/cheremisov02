# Лабораторная работа №3
## Работа с удалёнными репозиториями и совместная разработка в GitHub

### Цель работы
Изучить работу с удалёнными репозиториями, ветками, отправкой изменений и Pull Request. Освоить основы Code Review и защиты веток.

### Выполненные задания

1. Создана отдельная ветка lab0303-work.
2. Создана структура лабораторной работы.
3. Созданы файлы CONTRIBUTORS.md и MY_CONTRIBUTION.md.
4. Разработана функция add(a, b) на Python в файле calc.py.
5. Выполнен коммит и отправка изменений на GitHub.
6. Создан Pull Request из lab0303-work в main.
7. Изучен процесс Code Review и добавления комментариев к изменениям.
8. Создан файл history.txt с историей коммитов.

### Использованные команды

- git switch -c — создание новой ветки.
- git add — добавление файлов.
- git commit — сохранение изменений.
- git push — отправка изменений на GitHub.
- git log --oneline --graph --all — просмотр истории коммитов.

### Результат
В ходе работы создана отдельная ветка лабораторной работы, подготовлены файлы проекта, реализована функция сложения двух чисел и опубликованы изменения на GitHub с использованием Pull Request.

### Вывод
В результате лабораторной работы получены практические навыки работы с ветками, удалённым репозиторием, коммитами и Pull Request. Изучен принцип проверки изменений перед их объединением в основную ветку.
