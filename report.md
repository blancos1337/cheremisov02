## 6. Контрольные вопросы

### 1. Что такое система контроля версий?

Система контроля версий — это программный инструмент, позволяющий отслеживать изменения файлов проекта, сохранять историю изменений и возвращаться к предыдущим версиям.

### 2. Для чего предназначен Git?

Git — распределённая система контроля версий, предназначенная для управления изменениями в проектах, создания коммитов, веток и совместной разработки.

### 3. Чем отличается локальный репозиторий от удалённого?

Локальный репозиторий находится на компьютере пользователя и содержит историю изменений проекта. Удалённый репозиторий располагается на сервере, например GitHub или GitLab, и используется для хранения и обмена изменениями.

### 4. Для чего нужны команды git add и git commit?

Команда `git add` добавляет изменения в индекс для подготовки к фиксации. Команда `git commit` сохраняет подготовленные изменения в истории репозитория.

### 5. Что такое коммит?

Коммит — это зафиксированное состояние проекта в определённый момент времени. Он содержит информацию об изменениях и сообщение, описывающее выполненную работу.

### 6. Для чего используется файл .gitignore?

Файл `.gitignore` содержит список файлов и папок, которые Git не должен добавлять в отслеживание. Например, временные файлы, журналы и настройки среды разработки.

### 7. Что такое SSH-ключ и зачем он нужен?

SSH-ключ — это пара криптографических ключей: открытый и закрытый. Открытый ключ добавляется в GitHub, а закрытый хранится на компьютере. Они используются для безопасной аутентификации при подключении к удалённому репозиторию.

### 8. Для чего нужны команды git push и git pull?

Команда `git push` отправляет локальные коммиты в удалённый репозиторий. Команда `git pull` получает изменения из удалённого репозитория и объединяет их с текущей локальной веткой.
